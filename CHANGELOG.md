# Changelog

## [Unreleased]

- Spectra previews desktops, windows, capture cards and cameras with low latency, and picks a capture card's best mode by itself.
- The preview fits the window at its exact pixel size, or shows the source 1:1; on Windows, FSR 1.0 can upscale sources smaller than the preview.
- Recording in H.264, HEVC or AV1 on the GPU encoder, and full-resolution PNG screenshots.
- Spectra remembers the last source and its settings.
- Builds for Linux, macOS, Windows x64 and Windows ARM.
- Spectra's icon, colours and title-bar mark follow the brand.
- A Microsoft Store package for Windows x64 and ARM64, which can ship its own ffmpeg.
